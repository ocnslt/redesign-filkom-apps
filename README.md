# redesign-filkom-apps

Proyek ini merupakan prototipe redesign antarmuka (UI/UX) untuk web FILKOM Apps versi desktop dengan fokus pada tampilan yang lebih modern, bersih, dan responsif.

Hasil pengerjaan dapat diakses langsung melalui tautan berikut:
👉 [Live Demo - Redesign FILKOM Apps](http://ocnslt.github.io/redesign-filkom-apps)

## Cakupan Halaman
Proyek ini berfokus pada perbaikan tata letak untuk 3 halaman utama:
1. **Dashboard Utama (`index.html` / `dashboard.html`)** - Pusat informasi akademik mahasiswa.
2. **Layanan Konseling (`konseling.html`)** - Antarmuka untuk pengajuan bimbingan/konseling.
3. **Profil Pengguna (`profil.html`)** - Halaman informasi data diri mahasiswa.
   
*Catatan: Beberapa tombol atau konten pendukung sengaja dikosongkan karena proyek ini difokuskan pada visualisasi komponen utama di ketiga halaman tersebut.*

## Teknologi
* HTML5
* CSS3
* JavaScript (Vanilla)

## Struktur Repositori
Berkas utama diletakkan pada direktori akar (root) untuk kebutuhan deployment GitHub Pages:
* `index.html` / `dashboard.html` / `konseling.html` / `profil.html` - Berkas halaman web.
* `style.css` - Pengatur gaya visual.
* `script.js` - Logika interaksi antarmuka.
* `icons/` - Aset ikon pendukung.
